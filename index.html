SecMobApp

Mobile Security and Phishing Detection

SecMobApp helps users identify potentially dangerous websites and suspicious messages using security analysis.

Features

  • Website URL security analysis
  • Phishing indicators in messages
  • Gmail message analysis after user authorization
  • Security scan history stored locally on the device

Privacy

Gmail access is requested only with the user's permission. The application requests read-only access to Gmail messages.
